# 单词本

一个装在手机上的背单词小工具。没有账号、不上云，数据只存在你自己手机上。

老师发了词单，复制粘贴进来，之后就按记忆曲线自动安排复习：忘记 1 分钟后重来，模糊 10 分钟后重来，认识就 1 天、3 天、一周……一路拉长，最长一年。

---

## 一、装到手机上（只做一次，之后不用电脑）

仓库是公开的，但里面只有代码、没有你的词库 —— 数据始终只存在手机本地。

### A. Android 手机：装 APK（推荐）

有些 vivo / iQOO 手机装不了浏览器版（点「安装应用」没反应），所以有一个打包好的 App。

**下载地址：** https://liushaoquan133-collab.github.io/word-app/danci-v6.apk

1. 用**手机浏览器**打开上面的地址下载（别在微信里直接点开，微信不让装）。
2. 点开下载好的 `danci-v6.apk`。弹「去设置」就点它；没弹就手动开：设置 → 应用与权限 → 特殊应用权限 → 安装未知应用 → 找到刚才用的浏览器 → 允许。
3. 回来点「安装」，中途提示全选「继续 / 仍然安装」。
4. **第一次打开如果白屏，先别慌，也别卸载**：
   - 白屏 10 秒以内：正常，手机在初始化，等它；
   - 还没出来：直接再点一次图标；
   - 超过 30 秒还是白、或者出现带英文的报错页面：那才算问题，截图找码农。
5. 装完验收四条：
   - 桌面有「词」图标，点开是全屏，**没有地址栏**；
   - 加两个词，底部五个页签都能点开；
   - 长按图标「强行停止」，再打开 → 两个词还在（这条证明数据真存住了）；
   - 开飞行模式 → 点某个词的「🔊 发音」→ 要听到英文（有声说明用的是手机里的离线语音，不联网也能发音）。
     - 没声：去 设置 → 系统 → 语音引擎，下载英文语音包再试。还是没声就把点发音时弹出的原话截图发群里。

**更新版本**：下载新 APK 点开覆盖安装就行，**千万别卸载** —— 一卸载，词和进度全清。

这个 APK 没有任何权限（不联网、不读通讯录、不读存储），体积约 450 KB，`versionCode 6`。以后每次出新版都是同一个签名，覆盖安装不会丢数据。

### B. iPhone / 平板 / 电脑：用网页版

正式地址：**https://liushaoquan133-collab.github.io/word-app/**

1. **Android**：用 Chrome 打开地址 → 右上 `⋮` →「安装应用」（有的版本叫「添加到主屏幕」）→ 安装。
2. **iPhone**：必须用 Safari 打开 → 底部「分享」→「添加到主屏幕」→ 添加。
3. **装完立刻验收三条**：
   - 桌面有图标，点开是全屏，**没有地址栏**；
   - 开飞行模式再点图标，**还能进、能看到词、能开始学习**；
   - 设置里「导出备份」能正常下载出 json 文件。
4. 以后不用连电脑，联网时自动更新，断网照常背。

> **装之前先用手机打开一次这个地址。** github.io 在国内偶有不稳，电脑上通不代表手机通；打不开别硬装，找码农换托管（Cloudflare Pages / Netlify 都行）。

> **网页版和 APK 的数据不互通。** 两个是分开的存储，各自独立。之前在网页版加过词：网页版「设置 → 导出备份」存下 json → APK 里「设置 → 导入备份」选那个 json，词和进度就搬过去了。反过来也一样。

> **换过地址的话，数据要搬一次。** 之前在别的地址（比如 `http://192.168.x.x:8787`）上加过的词不会自动跟过来 —— 浏览器存储是按地址分开的。老地址打开 → 设置 →「导出备份」存下 json；新地址打开 → 设置 →「导入备份」选那个 json。两步在同一个浏览器里做完。

> **想看新版，要开两次。** App 的更新策略是先用缓存、再在后台悄悄更新：代码推送后，手机上第一次打开看到的还是旧界面，关掉再开第二次才是新版。不是没更新成功。APK 不受这条影响，APK 靠覆盖安装更新。

## 二、每天怎么用

1. **加词**：底部「加词」→ 把老师给的词单整段贴进去 → 填个标签（例如 `10-24 老师词单`，可不填）→ 点「解析预览」→ 看一眼解析结果（重复的词会划掉）→ 点「加入词库」。
   - 一行一个词，格式随意：
     ```
     1. abandon v. 放弃；抛弃
     2. ability n. 能力
     3. able adj. 能够的
     ```
   - 只给英文没给释义也行，学习时点一下卡片就能补。
   - 也可以点「选文件」，直接读 `.txt` / `.csv`。

2. **学**：回「今日」→ 点「开始学习」。
   - 先只看单词，想不起来就点卡片看释义（有音标会一起显示）。
   - 然后选：**忘记**、**模糊**、**认识**。按钮下面那行小字就是这一档真实的间隔（新词和复习词不一样，比如复习词点忘记是 10 分钟，不是 1 分钟）。
   - 一轮学完有完成页，能看到这一轮「认识 / 模糊 / 忘记」各多少。

3. **看进度**：底部「统计」——连续打卡天数、累计张数、未来 7 天要复习多少、掌握分布、最近 14 天热力图。

4. **查词**：底部「词库」——可以搜、可以按「新词 / 学习中 / 复习中 / 已掌握 / 暂停」筛。点任意一个词能改释义、改音标、暂停、重置进度、删除。

5. **设置**：每日新词上限（默认 50）、每日复习上限（默认 300）、显示单词时自动发音（用系统语音，不联网）。

## 三、数据存在哪

- 存在手机的本地存储里（`localStorage`），键名 `danci_v1`，数据格式版本 `v:1`。
- **只在这一台机器的这一份 App 里**。换浏览器、清浏览器数据、卸载重装，数据就没了。
- APK 版的数据在 App 自己的存储里，**和浏览器是分开的两份**：清浏览器缓存不会动 APK 里的词，清 APK 的缓存也不会动浏览器里的词。
- 但两者共一条铁律：**卸载 = 数据全清**。升级版本要覆盖安装，别卸载。
- 没有账号体系，也没有服务器，所以不存在"自动同步"。

## 四、备份、恢复、换手机

**备份**：底部「设置」→「导出备份（JSON）」→ 会下载一个 `单词本备份-2026-10-24.json`。
建议把这个文件丢到网盘或微信收藏，**每周导一次**。

**换手机 / 恢复**：
1. 新手机先按上面第一节把 App 打开。
2. 把备份 json 传到新手机（微信文件传输、网盘都行）。
3. App 里「设置」→「导入备份」→ 选这个 json。
4. 会提示"导入会覆盖当前所有数据"，确认即可。

注意：导入是**整个覆盖**，不是合并。两台手机各学各的话，别互相导，挑一台当主力，定期把它的备份存好。

**危险按钮**：设置里的「清空所有数据」要连续确认两次，清掉就真没了，先导出再点。

## 五、开发说明

原生 HTML/CSS/JS，没有框架、没有打包步骤，改完刷新就是新版。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架：一个 `#view` 容器 + 底部五个 tab |
| `app.css` | 全部样式（手机优先，按钮偏大） |
| `app.js` | 全部交互逻辑：存储、解析词单、渲染各页、评分、导出导入 |
| `srs.js` | 记忆曲线算法（UMD，Node 里也能直接测） |
| `sw.js` | Service Worker：页面网络优先；静态资源先用缓存、同时后台更新（改完文件把 `CACHE` 版本号 +1） |
| `manifest.webmanifest` | PWA 安装配置 |
| `icons/` | 图标 192 / 512 |
| `test/srs.test.js` | 单元测试（28 项：记忆曲线 + 词单解析） |
| `tools/` | 端到端和回归脚本（见下） |
| `android/` | APK 工程（WebView 壳 + 系统 TTS 桥），构建与发版见 `android/README.md` |

**跑单元测试**（改完 `srs.js` / `app.js` 里的解析逻辑必跑，28 项全过才算完）：

```
node test/srs.test.js
```

**跑全流程 / 回归**（需要本机 8787 端口有静态服务，脚本里 Edge 路径写死在 `tools/browser.js`）：

```
node tools/flow.js        # 全流程：加词→学习→三档评分→完成→统计→导出→刷新→PWA，截图进 shots/
node tools/audit.js       # 横向溢出回归：320/360/375/390/414 五种宽度 × 14 个界面 × 极端数据
node tools/pwa-check.js   # 本机可安装性：CDP 的 installabilityErrors、SW 接管、断网重开
node tools/live-check.js  # 线上验收：对已部署的 https 地址跑同一套检查（可传 URL 参数）
node tools/parse-check.js # 词单解析：跑 test/fixtures 下的真实 A 级样本，打印每行解析结果
```

**最近一次实测（2026-10-24）**：单元测试 28/28；`flow.js` 在 390 和 414 两档各 70 项断言全过（跑 414：`$env:VW='414'; node tools/flow.js`，跑线上：`$env:BASE='https://liushaoquan133-collab.github.io/word-app/'; node tools/flow.js`）；`audit.js` 5 种宽度 × 14 个界面共 70 个场景，页面级横向溢出 0、元素超宽 0；`pwa-check.js` 在 https 线上站点 `installabilityErrors` 为空、SW 已接管、断网可开；`chips-check.js` 词库筛选 6 个胶囊两行排开、全部在视口内（390/414 都是 0 横向滚动）。

**发布到线上**（GitHub Pages，仓库 `liushaoquan133-collab/word-app`，main 分支根目录）：

改完前端 → **先把 `sw.js` 的 `CACHE` 版本号 +1** → 再跑：

```
pwsh tools/deploy.ps1 "fix: 这次改了什么"
```

它只把 App 本体 8 个文件拷到发布目录并推 main，截图/测试/词单样本不进公开仓库。推完等 1–2 分钟，对线上跑一遍 `node tools/live-check.js`，exit 0 才算上线成功。

> 线上地址：https://liushaoquan133-collab.github.io/word-app/

**发 APK**：改完前端后 `assets/` 要从仓库根目录重新拷进 `android/app/src/main/assets/`，再跑构建，详见 `android/README.md`。铁律：`applicationId` 不变、**同一个 keystore**、`versionCode` 只升不降 —— 踩任何一条，用户就只能卸载重装，而卸载会清掉 `localStorage`，词全丢。

> Pages 上的 APK 只留最新一个，旧包删掉，避免装错。发完必须从线上 URL 下载回来核 `sha256`，本地 `dist` 副本不作数。

**2026-10-24 修的三个真 bug**：

1. **390 宽右侧被裁**：根因是词库筛选条 6 个胶囊 `white-space:nowrap` 一字排开共 492px，在 390/414 下右边两个（已掌握/暂停）被裁。已改成 `flex-wrap: wrap` 两行排开；另给 `.word-s` / `.preview .w` / `.modal h3` 加断词，并保留 `html { overflow-x: clip }` 兜底。
2. **SW 缓存把新版挡住**：`CACHE` 原来叫 `danci-v1`，改了 `app.css` 老用户还是旧样式。现在每改一次前端就升一档（当前 `danci-v6`），静态资源是「先用缓存、后台更新」，下次打开就是新版。
3. **三档按钮的时间是写死的**：复习词点「忘记」原来也提示「1 分钟后」，实际是 10 分钟。现在按钮下的小字用 `previewNext()` 拿副本跑一遍 SRS 算真实间隔（忘记/模糊/认识各算各的），不再误导。

**改完资源文件记得把 `sw.js` 的 `CACHE` 版本号 +1**，不然手机上第一次打开还是旧文件。

**铁律**：localStorage 的 key 和 `v:1` 格式不许动，否则阿全手机里已有的词全丢。要加字段只能在现有对象上增量加，读的时候给默认值。
